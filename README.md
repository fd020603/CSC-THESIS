# CSC-THESIS

## Introduction
A Python-based Proof of Concept (PoC) for interacting with local Large Language Models via Ollama, specifically optimized for the Llama-3 model.

사전 요구사항
Python 3.x

Ollama 설치 및 로컬 서버 실행 (포트 11434)

Llama-3 모델 다운로드
ollama run llama3

설치 및 실행
pip install requests

코드 실행
python poc2.py
